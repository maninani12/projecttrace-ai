# ADR 002: Conservative evidence before generation

Accepted. ZIP data is streamed without filesystem extraction or uploaded execution. Redaction precedes derived storage. Source/configuration signals and dependencies are distinct. README wording alone cannot establish a technology. Broader README statements remain inferred or unverified; database discrepancies are review candidates with explicit caveats. The ledger and citation IDs belong to immutable snapshots. AI summaries cannot become verified merely because a citation exists.
